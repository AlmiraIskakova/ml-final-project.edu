## Анализ результатов адаптивного тестирования

## Датасет представляет собой набор данных об учебной активности учеников при выполнении заданий. Он включает информацию о характеристиках заданий, использовании подсказок, времени выполнения, количестве попыток и других поведенческих признаках, которые используются для прогнозирования правильности ответа.

## Датасет

УЧЕБНЫЙ КОНТЕКСТ
position	позиция задания
РЕЗУЛЬТАТЫ ОБУЧЕНИЯ
correct	правильность ответа (0/1)
attempt_count	количество попыток
original	признак исходной версии задания
answer_type	тип ответа студента
ВРЕМЕННЫЕ ХАРАКТЕРИСТИКИ
ms_first_response	время до первого ответа (мс)
ИСПОЛЬЗОВАНИЕ ПОДСКАЗОК
hint_total	общее число подсказок
ОБУЧЕНИЕ И ПРОГРЕСС
opportunity	количество встреч с навыком
НАВЫКИ (SKILLS)
skill_name	название навыка
ПОВЕДЕНЧЕСКИЕ ПЕРЕМЕННЫЕ

Данный датасет содержит 317 322 записи и 9 столбцов, описывающих результаты выполнения заданий пользователями. В данных представлена информация о правильности ответов, количестве попыток, времени первого ответа, использовании подсказок, навыках и других характеристиках выполнения заданий. Датасет может использоваться для анализа учебного поведения, успеваемости пользователей, факторов, влияющих на правильность ответа, а также для построения моделей машинного обучения.

##Основные характеристики
•	Количество записей: 317 322
•	Количество столбцов: 9
•	Пропущенные значения: отсутствуют
•	Числовые столбцы: 7
•	Категориальные столбцы: 2

##Машинное обучение
Данные могут быть использованы для решения задачи бинарной классификации, где целевой переменной является: correct
Возможные модели
Для решения задач можно использовать:
•	Logistic Regression;
•	Decision Tree;
•	Random Forest;
•	CatBoost.

##Оценка модели
Для оценки качества классификации использовались метрики:
•	Accuracy;
•	Precision;
•	Recall;
•	F1-score;
•	ROC-AUC.
Особое внимание рекомендуется уделить F1-score и ROC-AUC, поскольку одной только Accuracy может быть недостаточно для полноценной оценки качества классификатора.
